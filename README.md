## 📈 GenAI-Driven Stock Sentiment Analysis

An AI-based system developed to analyze financial news using **Natural Language Processing, text embeddings, and Machine Learning**.

### 🔹 Key Highlights

- Compared **Word2Vec**, **BAAI/bge-base-en-v1.5**, and **all-MiniLM-L6-v2** embeddings.
- Compared **Random Forest** and **Neural Network** models.
- Performed sentiment classification on financial news.
- Achieved **61.4% test accuracy**.
- Achieved **60.2% F1-score** using all-MiniLM-L6-v2 with a Neural Network.

### 🧰 Technologies

`Python` `Pandas` `Scikit-learn` `TensorFlow` `Keras` `Sentence Transformers` `Word2Vec`
